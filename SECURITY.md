# RROTA Website Security

## Reporting a security issue

Please report website, account-safety, phishing, or product-security issues privately to **info@rrota.xyz**.

Include only the minimum evidence needed to reproduce or verify the issue. Never send seed phrases, private keys, recovery phrases, wallet passwords, authentication codes, or unrelated personal information.

Official verification and anti-phishing guidance is published at:

- https://rrota.xyz/verify
- https://rrota.xyz/proof
- https://rrota.xyz/links

## Public disclosure

Please allow reasonable time for investigation and remediation before public disclosure. Do not exploit an issue to access data, funds, accounts, or systems beyond what is strictly necessary to demonstrate the problem safely.
